# Use AniList's implicit grant with Auth Pin

Ship the public plugin with a maintainer-owned AniList client ID and use the implicit grant with AniList's Auth Pin redirect, avoiding both an embedded client secret and a backend. Because the resulting one-year token has broad account access, store it only in macOS Keychain, send it only to AniList's GraphQL endpoint, never log it or place it in preferences, and clear the paste field immediately; the accepted trade-off is brief clipboard exposure during connection. Plugin Reset overwrites the Keychain value with an empty credential because IINA exposes no deletion API, so an empty item may remain. Limit the IINA manifest to `network-request` and `show-osd`, allow only `graphql.anilist.co`, and request no filesystem, alert, or overlay access.
